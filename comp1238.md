## Week 1 - History
- Cuneiform was one of the earliest writing systems and was used in Mesopotamia.
- Gutenberg's printing press helped spread information and made books more accessible.

## Week 2 - Bits and Bytes
- A bit is a binary digit that can have two states: 0 or 1.
- A byte consists of 8 bits and is a standard unit used to store information.

## Week 3 - Text Structure
- Markdown is a lightweight markup language used to format text.
- HTML uses tags enclosed in angle brackets to structure web pages.

## Week 4 - Keyboards and Editors
- Touch typing improves accuracy, speed, and reduces cognitive load.
- VS Code is one of the most popular text editors and supports extensions for development.

## Week 5 - CLI
- The command line interface (CLI) allows users to interact with a computer using text commands.
- SSH is used to securely connect to and manage remote computers.
